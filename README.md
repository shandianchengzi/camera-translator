# Camera Translator · 镜头换算器

在线工具：https://shandianchengzi.github.io/camera-translator/

纯静态页面，无构建依赖。支持焦距与倍数换算、多个镜头比较、裁切像素尺寸、自定义传感器和成片比例、分辨率建议及取景范围演示。设置自动保存到浏览器 localStorage。

默认：目标 200mm，主摄 23mm、长焦 70mm，两个镜头均使用 **5000,0000 像素测试值**和方形传感器。倍数基准只包含当前存在的镜头。人眼通常约 50mm 仅作提醒，不参加对比。所有焦距按 35mm 等效焦距填写。

保留最初需求的简化估算 `总像素 / 放大倍数`，明确注明不是真实裁切关系；推荐用数码裁切的 `总像素 / 倍数²`。放大 2 倍时，宽和高各剩一半，面积与像素剩 1/4。目标焦距小于镜头焦距时，不增加像素，提示无法通过裁切获得更广视野。

像素 P 和传感器宽高比 a:b 对应 `√(P*a/b) × √(P*b/a)`；按成片方向摆放长短边后，在传感器范围内裁切到成片比例，不插值。方形 4000 × 4000 得到横屏 4000 × 2250 或竖屏 2250 × 4000。

分辨率按成片长边：1K 1024、2K 2048、4K 3840、8K 7680。建议向上选择一档，低于 1K 选 1K，超出 8K 选 8K。它是档位建议，不是清晰度保证；竖屏也按长边比较。

取景演示使用 Unsplash 的静态山湖照片，无法加载时回退到本地 `scene.svg`。取景框始终按线性倍数收缩，与选用哪种像素估算法无关。

## 页面布局

桌面端采用固定高度工作台：左侧参数栏调整共同目标和全部镜头，右侧始终显示取景画面与分辨率结果。页面无需上下翻；较多参数和镜头只在各自区域内部滚动。手机端点顶部“参数”打开可收起侧栏，取景与结果仍在固定工作区内。

## 使用方式

从手机官网参数或照片详情查找镜头的 **35mm 等效焦距**和支持像素（实际焦距依赖传感器尺寸，不能混填），填写参与对比的镜头。像素用完整数字，每四位加逗号：五千万显示 `5000,0000`，两亿显示 `2,0000,0000`。

所有镜头对比同一个目标。目标可以填写焦距，也可以在下拉框选择任意参与对比的镜头，然后输入相对倍数。手机显示的变焦倍数通常相对主摄 1×；如要照抄手机倍数，请选择自己的主摄作为基准。

取景滑块修改相对演示镜头的倍数，自动更新目标焦距。每张镜头卡片的分辨率滑块修改该镜头成片长边，通过当前像素算法与比例反算目标焦距；所有其他镜头和取景画面同步重算。超出镜头原始像素的要求会限制在原生焦距，不插值；焦距上限为 100000mm。

旧版以 MP 保存的镜头配置会自动转换为完整像素数，保留用户自定义参数。新增镜头、自定义比例、选择的基准、目标和取景镜头均保存到 localStorage。

可以在原图中拖动取景框、点击选取位置，或用方向键移动；放大画面随之更新。支持选择自己的照片：浏览器本地压缩到最长边 1600 像素的 JPEG Base64 后存入 localStorage，不上传服务器；遇到存储空间不足会提示不能保存到下次。支持恢复默认图片，照片与取景位置随设置一起保留。

## 开发与验证

直接打开 `index.html` 或使用任意静态服务器。运行 `node test.cjs` 检查公式、像素分组、数据迁移与分辨率反算。现有 GitHub Pages Action 还使用 Playwright 检查手机尺寸下的镜头选择、滑块联动、照片／取景位置保存、重载与旧数据迁移，然后发布。

GitHub Pages 工作流将根目录网页发布到 Pages；后续推送 main 分支自动部署。如果仓库 Pages 来源为分支部署，也可直接选择 main / root。
