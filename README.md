# Camera Translator · 镜头换算器

在线工具：https://shandianchengzi.github.io/camera-translator/

纯静态页面，无构建依赖。支持焦距与倍数换算、多个镜头比较、裁切像素尺寸、自定义传感器和成片比例、分辨率建议及取景范围演示。设置自动保存到浏览器 localStorage。

默认：目标 200mm，主摄 23mm、长焦 70mm，两个镜头均使用 **50MP 测试值**和方形传感器。人眼 50mm、手机主摄 23mm、Pocket 4 20mm 为可编辑的比较基准，不是设备规格认证。所有焦距按 35mm 等效焦距填写。

默认像素口径遵循需求：`总像素 / 放大倍数`。也提供更符合数码裁切几何关系的 `总像素 / 倍数²`。目标焦距小于镜头焦距时，不增加像素，提示无法通过裁切获得更广视野。

像素 P 和传感器宽高比 a:b 对应 `√(P*a/b) × √(P*b/a)`；按成片方向摆放长短边后，在传感器范围内裁切到成片比例，不插值。方形 4000 × 4000 得到横屏 4000 × 2250 或竖屏 2250 × 4000。

分辨率按成片长边：1K 1024、2K 2048、4K 3840、8K 7680。建议向上选择一档，低于 1K 选 1K，超出 8K 选 8K。它是档位建议，不是清晰度保证；竖屏也按长边比较。

取景演示使用 Unsplash 的静态山湖照片，无法加载时回退到本地 `scene.svg`。取景框始终按线性倍数收缩，与选用哪种像素估算法无关。

## 开发与验证

直接打开 `index.html` 或使用任意静态服务器。运行 `node test.cjs` 检查公式和边界条件。

GitHub Pages 工作流将根目录网页发布到 Pages；后续推送 main 分支自动部署。如果仓库 Pages 来源为分支部署，也可直接选择 main / root。
